AI Assist

AI Assist is a private, self-hosted voice assistant that runs on a single Raspberry Pi in one household. It is not a public service: only members of the household can use it, and there is no sign-up.

What it does with Google Calendar

A household member may link their Google account so the assistant can keep their tasks and reminders in sync with their Google Calendar:

  • reads the list of the user's calendars, so the user can choose which ones to sync;
  • reads, creates, updates and deletes events in the calendars the user selected.

The assistant does not use any other Google data.
